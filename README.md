## 🤖 Proyecto 2 — QA Test Generator (IA aplicada a QA)

**Repo:** [qa-test-generator](https://github.com/Rayjhoelblanco/qa-test-generator)
**Demo en vivo:** [rayjhoelblanco.github.io/qa-test-generator](https://rayjhoelblanco.github.io/qa-test-generator)

Motor self-hosted (n8n + API de Claude) que lee tickets de Jira/Trello y genera automáticamente escenarios Gherkin, esqueletos de tests en Playwright, y reportes de bugs estructurados. Incluye un ciclo de autoevaluación y reintento (orquestación agéntica), historial persistente en Google Sheets, y frontend público. Publicado en producción end-to-end.

**Stack:** n8n, API de Claude, JavaScript, Google Sheets API, GitHub Pages
